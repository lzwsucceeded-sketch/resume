# 李志伟｜个人专业作品集

本仓库用于托管个人作品集网站，内容依据个人中文简历整理，重点展示水文地质、地下水数值模拟、GIS 与水资源调查评价相关经历。

## 本地预览
直接使用浏览器打开 `index.html`。

## GitHub Pages 部署
1. 进入仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/(root)`，点击 Save。
4. 等待 GitHub Pages 完成部署。

网站地址： https://lzwsucceeded-sketch.github.io/resume/
